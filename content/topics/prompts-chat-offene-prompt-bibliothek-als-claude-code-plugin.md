prompts.chat, früher als „Awesome ChatGPT Prompts“ bekannt, nennt sich selbst die größte offene Prompt-Bibliothek. Sie lässt sich laut einem Video mit einem offiziellen Plugin in Claude Code einbinden, sodass Claude passende Prompts selbst heraussucht. ## Hintergrund und Verbreitung

- Das Projekt war früher unter dem Namen „Awesome ChatGPT Prompts“ bekannt. [Q:2026-10-23-prompts-chat-groesste-offene-prompt-bibliothek-dir]
- Es nennt sich selbst die größte offene Prompt-Bibliothek. [Q:2026-10-23-prompts-chat-groesste-offene-prompt-bibliothek-dir]
- Laut Video hat das Projekt auf GitHub 173.000 Sterne. [Q:2026-10-23-prompts-chat-groesste-offene-prompt-bibliothek-dir]

## Umfang und Inhalt

- Der Sprecher des Videos zählte am 16.10. über die öffentliche Schnittstelle 2.482 Prompts. Sie decken Texte, Code, Bilder, Videos und Recherche ab. [Q:2026-10-23-prompts-chat-groesste-offene-prompt-bibliothek-dir]
- Darunter befinden sich 104 Agent-Skills. [Q:2026-10-23-prompts-chat-groesste-offene-prompt-bibliothek-dir]

## Nutzung in Claude Code

- Mit dem offiziellen Plugin lässt sich die Bibliothek mit zwei Befehlen in Claude Code holen. [Q:2026-10-23-prompts-chat-groesste-offene-prompt-bibliothek-dir]
- Anschließend sucht Claude einen passenden Prompt heraus und fügt ihn ein. [Q:2026-10-23-prompts-chat-groesste-offene-prompt-bibliothek-dir]
- Das Suchen ist laut Video ohne Konto möglich. [Q:2026-10-23-prompts-chat-groesste-offene-prompt-bibliothek-dir]

## Einschränkungen

- Die meisten Prompts stammen von Nutzern der Plattform. [Q:2026-10-23-prompts-chat-groesste-offene-prompt-bibliothek-dir]
- Sie sind überwiegend auf Englisch. [Q:2026-10-23-prompts-chat-groesste-offene-prompt-bibliothek-dir]
- Ihre Qualität ist unterschiedlich, die Prompts sollten also vor der Verwendung geprüft werden. [Q:2026-10-23-prompts-chat-groesste-offene-prompt-bibliothek-dir]
