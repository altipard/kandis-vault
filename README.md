# Kandis-Vault

Inhalt dieses Repos wird von [kandis](https://github.com/altipard/kandis) geschrieben und
per GitHub Actions mit Zola als Website veröffentlicht.

- `content/topics/` Themenseiten, vom LLM gepflegt
- `content/sources/` eine Seite pro eingeworfener Quelle
- `templates/`, `static/` Zola-Theme

Lokal bauen: `zola serve`
